Overview

Motion Tracker Lab helps researchers measure and analyze the motion of real objects captured on video. It replicates core features of desktop tools like Tracker, but running entirely in the browser with no installation required.

Getting Started

  1. Upload a video, or click 🎥 Load Sample Video to try it without one.
  2. Complete calibration: Set Scale → Set Origin → Set Axes.
  3. Click Start Tracking and click the object's position on each frame.
  4. Review the Data Table and plot Graphs, optionally with a fit.
  5. Export as CSV, copy to clipboard, or export a graph as PNG.

Open 🧭 Workflow any time for a live checklist of these steps.

Video Controls

  • ⏮ ◄ ▶ ► — reset, step back/forward one frame, play/pause. Choose the camera's mode under RECORDED FPS. The app automatically handles frame stepping and slow-motion time correction.
  • For slow-motion clips, choose the recorded frame rate shown in the phone's video information. If it reports an unusual value (for example, 217.35 fps), choose Custom (slow motion) and enter that value. Existing measurements, velocities, accelerations, and graphs are recalculated automatically.
  • Scrubber — drag to seek anywhere.
  • Hide/Show Overlay — toggles calibration markers, axes, and trajectory visibility without deleting data.
  • Zoom (100–300%) with a pan pad — for precise clicks on small objects.
  • The origin marker and axis lines are draggable directly on the canvas after they're placed, for fine-tuning.

Calibration

  • 1. Set Scale — click two points spanning a known real-world distance, then enter that distance and unit (m/cm/mm). Assumes a single isotropic px/unit ratio with no perspective distortion.
  • 2. Set Origin — click the point that becomes (0, 0).
  • 3. Set Axes — click a point in the intended +x direction (useful for tilted cameras or inclined ramps), and choose Physics (y↑) or Screen (y↓) coordinates.

Re-confirming any calibration step after tracking automatically recalculates every point's real-world coordinates — no need to re-track.

Tracking Points

  • Auto-advance frame after click — steps to the next frame automatically after each click.
  • Undo Last — removes the most recent point.
  • Clear All — removes every tracked point (confirmation required).

Data Table & Graphs

Each row records frame, time, pixel coordinates, real (x, y) coordinates, and velocity (vx, vy). Graphs can plot x(t), y(t), y vs x (trajectory), vx(t), vy(t), ax(t), or ay(t), with an optional linear or quadratic least-squares fit and R².

  • x(t) / vx(t) / vy(t) → linear fit slope ≈ constant velocity/acceleration (≈ g for vy in free fall)
  • y(t) / y(x) → quadratic fit, 2a ≈ constant acceleration for y(t)

The tool reports whatever best-fit curve you choose — it doesn't validate that the motion actually matches that model.

Exporting Results

  • Export CSV — frame, time, pixel/real coordinates, velocity, and acceleration for every point.
  • Copy — tab-separated data for pasting into a spreadsheet.
  • Export PNG — the current graph as an image.

How the Math Works

Velocity and acceleration are numerical derivatives (finite differences) of the calibrated positions — not a smoothed curve fit. Central differences are used at interior points (second-order accurate); forward/backward differences at the first/last point, which is why endpoints tend to look noisier.

Because differentiation amplifies clicking error, small mistakes matter more for velocity, and even more for acceleration.

Supported Video Formats

  • MP4 (H.264) — ✅ all browsers (recommended)
  • WebM (VP8/VP9) — ✅ all browsers
  • MOV — ⚠️ browser-dependent, may not work in Chrome

Limitations

  • Frame accuracy depends on the browser's seek precision and a correctly-set FPS. Slow-motion correction must also match the recording-to-playback speed ratio.
  • No automatic object detection or multi-object tracking; tracking is manual and single-trajectory.
  • Calibration assumes a distortion-free, perpendicular camera view.
